# student-performance-analysis
Student performance analysis using Python, SQL, Excel and Power BI
## Project Overview

This project analyzes student academic performance to understand how study hours, attendance, assignments, and other factors relate to final exam performance.

## Tools & Technologies

- Python
- Pandas
- SQL
- Power BI

## Dataset

The dataset contains student information including:

- Student ID
- Gender
- Age
- Department
- Study Hours
- Attendance
- Assignment Score
- Midterm Score
- Final Score

## Analysis Performed

### Python
- Loaded and explored the dataset using Pandas
- Checked for missing values
- Calculated summary statistics
- Analyzed department-wise performance
- Identified top-performing students
- Examined study hours and attendance in relation to final scores

### SQL
- Calculated average final scores
- Compared performance across departments
- Identified top-performing students
- Analyzed study hours and final scores
- Identified students with low attendance or low performance

### Power BI
Created an interactive dashboard to visualize:
- Average final score
- Student performance
- Department-wise performance
- Attendance
- Study hours

## Key Objective

The main objective is to identify patterns in student performance and understand factors that may contribute to better academic outcomes.

## Project Files

- `student_performance.csv` – Dataset
- `analysis.py` – Python analysis
- `analysis.sql` – SQL queries
- `dashboard.pbix` – Power BI dashboard
